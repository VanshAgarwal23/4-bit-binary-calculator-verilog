# 4-Bit Binary Calculator Using Verilog

A **4-bit combinational binary calculator** designed and verified in
**Verilog HDL** using **AMD/Xilinx Vivado**. The calculator supports
**4-bit addition and subtraction**, with a **2:1 multiplexer implemented
using NOT, AND, and OR gates** to select the required operation.

This project demonstrates practical concepts from **Digital Electronics,
Verilog HDL, RTL design, combinational logic, hierarchical module
design, simulation, and FPGA synthesis**.

------------------------------------------------------------------------

## 📌 Project Overview

The calculator accepts two 4-bit binary operands:

-   `A` --- First operand
-   `B` --- Second operand
-   `SEL` --- Operation selection signal

The operation is selected as follows:

   `SEL`  Operation     Output
  ------- ------------- ---------
    `0`   Addition      `A + B`
    `1`   Subtraction   `A - B`

The selected result is available on `RESULT[3:0]`.

`CARRY_BORROW` indicates:

-   **Carry** during addition
-   **Borrow** during subtraction

### Architecture

``` text
              ┌─────────────────┐
       A ────►│   4-bit Adder   │──── ADD_RESULT ──┐
       B ────►│                 │                   │
              └─────────────────┘                   │
                                                    ▼
                                               ┌─────────┐
                                               │  2:1    │────► RESULT
              ┌─────────────────┐               │   MUX   │
       A ────►│ 4-bit Subtractor│──── SUB_RESULT│         │
       B ────►│                 │               └─────────┘
              └─────────────────┘                    ▲
                                                     │
                                                    SEL
```

Both arithmetic operations are calculated in parallel, and the
multiplexer selects the result required by `SEL`.

## 🧩 Design Modules

### 1. 4-Bit Adder

**File:** `Four_bit_adder.v`

Performs:

``` text
A + B
```

Outputs:

``` text
SUM   → 4-bit result
CARRY → carry-out
```

The 5-bit expression `{CARRY, SUM}` preserves the carry generated by the
addition.

------------------------------------------------------------------------

### 2. 4-Bit Subtractor

**File:** `four_bit_subtractor.v`

Performs:

``` text
A - B
```

Outputs:

``` text
DIFF   → 4-bit result
BORROW → borrow indication
```

When `A < B`, the 4-bit result is represented using two's complement.

Example:

``` text
3 - 5 = -2

3  = 0011
5  = 0101
--------------
     1110
```

`1110` represents `-2` in 4-bit two's-complement representation, with
`BORROW = 1`.

------------------------------------------------------------------------

### 3. 2:1 Multiplexer

**File:** `mux.v`

The MUX selects between the addition and subtraction results.

Its logic is:

``` text
RESULT = (~SEL & ADD_RESULT) | (SEL & SUB_RESULT)
```

The MUX is explicitly constructed from:

``` text
NOT gates
AND gates
OR gates
```

This makes the underlying digital-logic implementation visible at the
RTL level.

> During FPGA synthesis, Vivado optimizes the gate-level RTL into the
> device's LUT-based architecture. Therefore, separate physical
> AND/OR/NOT gates are not necessarily visible in the post-synthesis
> schematic.

------------------------------------------------------------------------

### 4. Calculator Top Module

**File:** `calculator.v`

The top-level module instantiates the adder, subtractor, and MUX.

``` text
SEL = 0 → RESULT = ADD_RESULT
SEL = 1 → RESULT = SUB_RESULT
```

It also selects the appropriate status output:

``` text
SEL = 0 → CARRY_BORROW = ADD_CARRY
SEL = 1 → CARRY_BORROW = SUB_BORROW
```

## 🧪 Verification

The design is verified using:

**Testbench:** `calculator_tb.v`

The testbench applies seven test cases covering normal operation and
boundary conditions.

    Test       A            B        SEL  Operation    Expected Result   Carry/Borrow
  ------ ------------- ------------ ----- ----------- ----------------- --------------
       1  `0101` (5)    `0011` (3)    0   5 + 3          `1000` (8)           0
       2  `1001` (9)    `0010` (2)    0   9 + 2          `1011` (11)          0
       3  `0101` (5)    `0011` (3)    1   5 - 3          `0010` (2)           0
       4  `1001` (9)    `0100` (4)    1   9 - 4          `0101` (5)           0
       5  `1111` (15)   `0001` (1)    0   15 + 1         `0000` (0)           1
       6  `0111` (7)    `0111` (7)    1   7 - 7          `0000` (0)           0
       7  `0011` (3)    `0101` (5)    1   3 - 5          `1110` (-2)          1

The behavioral waveform was verified against the expected outputs for
all seven cases.

### Simulation Timeline

``` text
0–10 ns    → 5 + 3 = 8
10–20 ns   → 9 + 2 = 11
20–30 ns   → 5 - 3 = 2
30–40 ns   → 9 - 4 = 5
40–50 ns   → 15 + 1 = 0, Carry = 1
50–60 ns   → 7 - 7 = 0
60–70 ns   → 3 - 5 = -2, Borrow = 1
```

The waveform configuration is included as:

``` text
Docs/calculator_tb_behav.wcfg
```

## 🚀 How to Run

### Prerequisites

Install:

-   AMD/Xilinx Vivado
-   Git (optional, for cloning the repository)

### 1. Clone the repository

``` bash
git clone https://github.com/VanshAgarwal23/4-bit-binary-calculator-verilog.git
```

### 2. Open the Vivado project

Open:

``` text
4-bit binary Calculator using Verilog.xpr
```

in Vivado.

### 3. Run Behavioral Simulation

In Vivado:

``` text
Flow Navigator
→ Simulation
→ Run Simulation
→ Run Behavioral Simulation
```

The testbench automatically applies the verification vectors.

### 4. Run Synthesis

From the Flow Navigator:

``` text
Synthesis
→ Run Synthesis
```

The design can then be inspected through Vivado's utilization and
schematic reports.
